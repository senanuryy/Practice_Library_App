# Practice_Library_App
This project aims to develop a book registration application. The system allows you to save book information such as Title, Author First Name, Author Last Name, Page Count, Publisher, and Registration Date.

## Project Features

- **Book Objects:** Books are stored as objects containing the following information:
  - **BookTitle** (Book Title)
  - **AuthorFirstName** (Author First Name)
  - **AuthorLastName** (Author Last Name)
  - **PageCount** (Page Count)
  - **Publisher** (Publisher)
  - **RecordDate** (Registration Date)

- **Constructor:**
  - Default constructor: Creates an object without parameters and sets the registration date to the current date.
  - Parameterized constructor: Takes book details as parameters and sets them while creating the object.
